# 寻灯者｜公开早期源代码快照

文档版本：`v0.2`  
快照版本：`v0.43.96`  
状态：`SANITIZED_PUBLIC_CANDIDATE / PRE_SKILL_INTEGRATION`

## 内容范围

本快照只保留 Unity 项目必要源目录：

- `Assets/`
- `Packages/`
- `ProjectSettings/`

该快照不包含 Unity `Library/`、`Temp/`、`Logs/`、`obj/`、编译中间目录、APK、内部工具、协作规则、音效源文件或本地工作区文件。

## 公开前检查

- 本目录不代表当前主工作区最新版本；
- C01–C06 技能接入不包含在该早期快照中；
- 发布前仍需复核商业素材、第三方素材署名和 Unity 设置；
- 仅建议先放入 GitHub 私有仓库，确认可克隆和可重建后再公开。

## 打开方式

1. 安装 Unity `2022.3.62f3c1`；
2. 在 Unity Hub 中选择本目录作为项目目录；
3. 等待 Unity 根据 `Assets/`、`Packages/` 和 `ProjectSettings/` 重新生成本地缓存；
4. 不要把生成的 `Library/`、`Temp/`、`Logs/` 或 `obj/` 提交回仓库。

## 第三方内容

公开发布前，请在游戏内“关于本作/制作人员”和仓库 README 中补齐第三方字体、图片、音效的作者、来源页面和许可证署名。当前快照不包含主工作区的音效源文件和内部署名登记表。
