## 5. 游戏内入口与展示字段

1. 入口：主页右上菜单 → 设置 → 致谢与许可。
2. 页面分类：音乐、音效、字体。
3. 每条至少展示作品或素材名、作者或平台、用途、许可名、来源链接和许可链接。
4. 页面使用既有正式通用 UI 资源与运行时动态文字，不把参考截图或新生成图形作为运行时美术资源。
5. 中英文内容由同一运行时清单生成，避免两套清单漂移。

## 6. 公开仓库边界

1. 上述资源只作为完整游戏工程的组成部分使用，不得从本仓库抽取后组成或销售独立字体、音乐或音效素材包。
2. 私有开发仓库可以保留运行所需资源和本说明。
3. 将仓库设为公开前，仓库维护者必须重新确认平台当期许可是否允许源码仓库中的文件级分发；无法确认时，应改用自制资源、可明确再分发的资源，或仅发布不含受限二进制素材的代码版本。
4. 原始第三方源文件、候选素材库和内部来源归档不进入公开 Unity 工程；这里只保留游戏运行实际需要的资源。
5. 后续替换资源时，必须同步更新本文和游戏内清单，并按运行时资源生命周期规范退出旧资源。
