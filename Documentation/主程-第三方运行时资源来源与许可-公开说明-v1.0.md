## 4. 公开仓库边界

1. 上述资源只作为完整游戏工程的组成部分使用，不得从本仓库抽取后组成或销售独立字体、音效素材包。
2. 私有开发仓库可以保留运行所需派生资源和本说明。
3. 将仓库设为公开前，仓库维护者必须重新确认平台当期许可是否允许源码仓库中的文件级分发；无法确认时，应改用自制资源、可明确再分发的资源，或仅发布不含受限二进制素材的代码版本。
4. 原始第三方源文件、候选素材库和内部来源归档不进入公开 Unity 工程；这里只保留游戏运行实际需要的派生资源。
5. 后续替换资源时，必须同步更新本文件并按运行时资源生命周期规范退出旧资源。
